# DormFit submission checklist

## Project documents

- [x] `devpost/scope.md` explains what the app does and who it helps.
- [x] `devpost/prd.md` explains how users work with the app.
- [x] `devpost/spec.md` explains how the app works.

## Before submitting

- [ ] Test the latest version and fix any remaining problems.
- [ ] Check that the GitHub repository is public and shows the MIT license.
- [ ] Make sure the demo video is public and under 3 minutes.
- [ ] Check that the project page, video and public code link open for judges.

The Skill Pack includes an app-map as a learning wrap-up. Devpost's published submission rules do not list the app-map as a file to submit, so it is not a submission task here.
